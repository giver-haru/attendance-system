# 画面遷移図

`Main.java`のルーティング定義と`AuthFilter`のアクセス制御に基づく画面遷移。

```mermaid
flowchart TD
    Start(["未ログイン状態でアクセス"]) --> Login["S01 ログイン画面\n/login"]

    Login -->|"認証OK"| Dashboard
    Login -->|"認証NG"| Login

    Dashboard{"S02 ダッシュボード\n/dashboard"}
    Dashboard -->|"社員"| DashEmp["社員向け表示\n本日の打刻状況・当月サマリー・有給申請状況"]
    Dashboard -->|"管理者"| DashAdmin["管理者向け表示\n承認待ち件数・チーム本日勤怠"]

    DashEmp -->|"出勤する/退勤する ボタン"| Clock["/clock (POST)\n打刻処理"]
    Clock --> Dashboard

    DashEmp -->|"＋新しく有給を申請する"| LeaveReq["S04 有給申請画面\n/leave/request"]
    LeaveReq -->|"申請する"| Dashboard
    LeaveReq -->|"入力エラー"| LeaveReq

    DashAdmin -->|"承認画面へ"| LeaveApprove["S05 有給承認画面\n/leave/approve"]
    LeaveApprove -->|"承認 / 却下"| LeaveApprove

    DashAdmin -->|"今月の勤怠をCSVで出力"| CsvExport["/export/csv\nCSVダウンロード"]

    Dashboard -->|"勤怠一覧 nav"| AttendanceList["S03 勤怠一覧画面\n/attendance"]
    AttendanceList -->|"nav"| Dashboard

    Dashboard -->|"ログアウト"| Logout["/logout"]
    LeaveApprove -->|"ログアウト"| Logout
    AttendanceList -->|"ログアウト"| Logout
    Logout --> Login

    Dashboard -->|"未ログインでアクセス試行"| Login
    LeaveApprove -.->|"社員が直接アクセス→403"| Forbidden(["403 Forbidden"])
    CsvExport -.->|"社員が直接アクセス→403"| Forbidden
```

## 補足

- `/leave/approve` と `/export/csv` は`AuthFilter`の`ADMIN_ONLY_PATHS`により管理者以外は403。
- `/login`・`/`・`/static/style.css`のみ未ログインでアクセス可能（`PUBLIC_PATHS`）。それ以外は未ログインなら`/login`へ強制リダイレクト。
- ヘッダーナビゲーション（`Layout.navFor`）は「ダッシュボード」「勤怠一覧」が共通表示、「承認待ち一覧」は管理者のみ表示。
